欢迎来到我的博客！👋

这是第一篇文章。折腾了很多工具之后，决定还是给自己留一块安静的地方写东西。

## 为什么写博客

- **整理思路**：写下来才知道自己是真的懂了
- **记录折腾**：AI Agent、macOS 自动化、后端工程
- **对抗遗忘**：好记性不如烂笔头

## 技术栈

这个博客用 [Astro](https://astro.build/) 构建，主题是 [Fuwari](https://github.com/saicaca/fuwari)，托管在 GitHub Pages 上。

```bash
pnpm new-post my-new-post   # 新建文章
pnpm dev                    # 本地预览
pnpm build                  # 构建
```

以后会陆续更新一些技术笔记，欢迎常来看看。
