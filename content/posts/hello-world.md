这是第一篇文章。折腾了很多工具之后,决定还是给自己留一块安静的地方写东西。

## 为什么写博客

- 整理思路:写下来才知道自己是真的懂了
- 记录折腾:macOS 自动化、AI Agent、后端工程
- 对抗遗忘:好记性不如烂笔头

## 技术栈

这个博客用 [Hugo](https://gohugo.io/) 生成,主题是 [PaperMod](https://github.com/adityatelange/hugo-PaperMod),托管在 Gitee Pages 上。

```bash
hugo new posts/my-new-post.md   # 新建文章
hugo server -D                  # 本地预览
hugo                            # 构建到 public/
```

以后会陆续更新一些技术笔记,欢迎常来看看。
